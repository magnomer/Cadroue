# LNeutralAnalyze.cs

## `public static LNeutralWheel LNeutralAnalyzeResolve(`

Estimate where an automatic method's neutral point falls in the current frame, for the display-only wheel dot.
Average = per-channel mean, Median = per-channel median, Minmax = per-channel midpoint.
The actual export correction is computed by ffmpeg's colorcorrect.
This only previews the resulting cast direction.
