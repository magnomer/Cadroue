## `public static class LInventoryEngine`

The single ShellEngine owner of the question whether the active FFmpeg build lists a filter.
The engine never names the Infrastructure inventory, so the host assigns the seam at startup.
The test relay assigns the same seam, so tests ask the same inventory.

## `public static Func<string, bool> LInventoryFilterSeam { get; set; } = _ => true;`

Unattached, it answers true, matching the inventory rule that an empty filter list fails open.
