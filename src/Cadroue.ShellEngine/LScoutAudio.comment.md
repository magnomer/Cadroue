## `internal static async Task<LScoutAudioInterval?> LScoutAudioResolve(`

The packet probe passes no work id, because a probe never pauses with the queue.
Null means the probe failed, so callers can tell an unknown answer from a confirmed silent range.
Packet times are shifted by the container start time, so the offset is relative to the requested origin.
