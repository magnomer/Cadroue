## `public static partial class LMessenger`

The request boundary between a mode tab and the worklist pipeline.
The engine never names the Deportment, so its owners assign each source when they attach.
Every source is optional, and an unassigned one reads as empty, zero or skipped.

## `private static void LMessengerDefer(Action lMessengerAction)`

Routes a schedule-mutating action onto the post thread the worklist writes on.
It falls back to inline when no post owner is wired.
