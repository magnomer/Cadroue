## `public static partial class LMessenger`

Turns an Edit tab request into work items and routes them into the schedule.
Without an export encoding nothing is queued and the count is zero.
The single-source form uses the crop and video steps the tab supplies, under the caller's batch.
The list form reads each source's saved edit plan.
List sources without a batch of their own share one batch minted for this request.
The list form also tells the planner whether the FFmpeg build offers the eq filter.
That answer comes through LInventoryEngine, so this file never names the Infrastructure inventory.
Created items then get their source sizes and a deferred LSubsidiary measurement.
