# Registry

This folder holds every generated registry the name audit compiles against, and nothing hand-written.
Each file is generated by `SyncNames.ps1` from `docs-internal` and must never be edited by hand.
No generated file outgrows the line limit, so the bases, verbs and exemptions are split over several files.
Every file carries the generated-file header.
The comment audit exempts each of them by file name, from the exemption list in the project's settings files.

## `TAuditExemptRegistry`

This exemption registry holds the exemptions apart from the bases and the verbs.
An entry too wide for one line keeps its key once and wraps its file list below it.

## `TAuditLogicRegistry`

This base registry holds the bases of the `Logic` block of `ListObject.md`.
It carries the generation the convention compares with the setting generations.

## `TAuditSharedRegistry`

This base registry holds the bases of the `Shared` block of `ListObject.md`.
It carries the generation the convention compares with the setting generations.

## `TAuditTestRegistry`

This base registry holds the bases of the `Test` block of `ListObject.md`.
It carries the generation the convention compares with the setting generations.

## `TAuditUIRegistry`

This base registry holds the bases of the `UI` block of `ListObject.md`.
It carries the generation the convention compares with the setting generations.

## `TAuditVerbRegistry`

This verb registry holds the verbs apart from the bases and the exemptions.
